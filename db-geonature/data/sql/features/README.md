# Dossier features

Ce dossier devrait contenir tous les fichiers SQL modifiant la base de données GeoNature du SINP AURA.
Les fichiers devraient être maintenu compatibles avec la version courrante du GeoNature utilisé
sur le SINP AURA.

A l'exception des données (observations, medias, textes...), ces fichiers 
doivent permettre de configurer et compléter les éléments manquant 
(hors révisions et branches Alembic) lors d'une installation de GeoNature 
depuis les sources.
